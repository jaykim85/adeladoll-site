인형 이야기

포슬린 인형을 처음 보시는 분들을 위한 짧은 안내입니다.

01

앤틱 원본 (Original Antique)

1880년대부터 1910년대 사이 독일과 프랑스의 인형 공장에서 만들어진 100년이 넘은 인형입니다. 목 뒤에 제작사 마크와 몰드 번호, 크기 번호가 새겨져 있습니다.

02

앤틱 복제 (Antique Reproduction)

앤틱 원본 인형에서 뜬 몰드로 현대의 작가가 다시 만든 인형입니다. 원본과 같은 얼굴이지만 굽는 과정에서 조금 작아지며, 머리 뒤에 작가의 이니셜과 제작 연도가 새겨집니다. 원본이 너무 귀해 직접 보기 어려운 명작들을 가까이에서 만날 수 있게 해 줍니다.

03

모던 아티스트 돌 (Modern Artist Doll)

현대 작가가 직접 조각한 원형으로 만든 인형입니다. 실제 사람의 자연스러운 표정과 체형, 오늘날의 감각이 담겨 있으며, 원형 작가와 이를 완성한 제작자가 다른 경우가 많습니다.

자주 나오는 용어

비스크 (Bisque)
유약을 바르지 않고 구운 도자기. 광택 없이 살결 같은 질감을 냅니다.
몰드 (Mold)
인형 헤드와 팔다리를 성형하는 석고 틀. 몰드 번호는 얼굴 모양을 구분하는 번호이며 제작연도가 아닙니다.
DEP
프랑스어 Depose, 독일어 Deponirt의 약자로 '등록된 디자인'이라는 뜻입니다.
슬립 아이 (Sleep eyes)
인형을 눕히면 감기고 세우면 뜨이는 유리 눈. 머리 안쪽의 추로 움직입니다.
컴포지션 바디
종이, 톱밥, 풀 등을 섞어 굳힌 재료로 만든 몸체(앤틱). 현대 복제 인형은 몰드로 주조한 합성 소재의 바디를 쓰며, D.A.G 앤틱 복제 부문에서도 인정됩니다.
숄더 헤드 / 소켓 헤드
어깨까지 한 덩어리로 만든 헤드는 천이나 가죽 바디에, 목까지만 만든 소켓 헤드는 관절 바디에 끼웁니다.
돌리 페이스 / 캐릭터 돌
이상화된 예쁜 아이 얼굴이 돌리 페이스, 1909년 이후 실제 아이를 본떠 만든 자연스러운 표정의 인형이 캐릭터 돌입니다.
파리안 / 차이나 돌
피부색을 입히지 않거나 아주 옅게만 입힌 무광 비스크에 머리카락까지 조형한 1860-1880년대 독일 인형이 파리안. 같은 형태에 유약을 발라 광택이 나면 차이나 돌입니다.
D.A.G
Doll Artisan Guild. 1977년 창립된 포슬린 인형 제작자들의 국제 조직으로 세미나, 자격 인증, 국제 대회를 운영합니다.
레이디 돌 / 베베
성인 여성 모습의 인형이 레이디 돌(패션 돌, 푸페), 아이 모습의 프랑스 인형이 베베입니다.
