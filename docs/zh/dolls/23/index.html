关于这件人偶

这是人偶「埃洛伊丝(Elouise)」，一头铂金色长卷发，身穿白色蕾丝衬衫、缎面束身衣与薄纱裙。作品出自Lynn Harrison之手，原型与模具由英国艺术家Bunny Morris与Paul Jackson制作。

这款模具为限量版，从未进行商业化生产。由于没有出售的模具，只有参加过艺术家亲自主持的研习班的人才能制作，因此这件人偶更加难得一见。

背景故事

Bunny Morris与Paul Jackson是共同雕塑人偶原型的艺术家组合，通过Seeley's发布了18英寸全瓷儿童人偶「Angel」、半身像「Claire」、30英寸少女系列「Daisy Garland」以及精灵系列等。Bunny Morris还以可插拔更换四肢的5英寸迷你人偶「Popit」的「Dollies Galore」系列而闻名。

研习班专用模具是瓷人偶世界独特的传统。艺术家不公开出售自己的原型，而将其限定于亲自授课的研习班中使用，参加者便能原原本本地学到艺术家的彩绘方法与服装制作方式，同时完成数量有限的人偶。这样的人偶既凝聚着艺术家的手艺，也承载着研习班的记录。
