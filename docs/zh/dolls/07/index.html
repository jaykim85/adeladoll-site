关于这件人偶

这是一件金色卷发、身穿淡蓝色网纱长裙的人偶。以白色蕾丝收边的袖口和前襟以及刺绣装饰都十分用心，蓝色眼睛和红润的脸颊透出孩童般的神态。

这是用德国 Armand Marseille 的模具390制作的古董原作，制作于约1905-1920年。390是 Armand Marseille 产量最多的模具，是将插接式头部安装在关节式复合材料身体上的典型「娃娃脸」少女人偶。

背景故事

模具390从1900年左右到1930年代，几十年间大量生产，成为如今最常见的德国古董人偶。颈后有「Armand Marseille / Germany / 390 / A (尺寸) M」格式的标记，玻璃睡眠眼、露齿的张开嘴和马海毛假发是基本配置。与同公司的370作为肩式头部用于小羊皮身体不同，390是插接式头部，嵌入复合材料身体使用。

Armand Marseille 于1856年出生于俄国圣彼得堡，1860年代移居德国，1885年收购图林根克佩尔斯多夫的瓷器工厂，开始制作人偶头部。全盛期工厂每天生产约1,000个头部，是世界最大规模的制造商之一；1919年与 Ernst Heubach 合并，1932年分离后不久便停止了生产。将这件作品与本系列的2号(模具1894)并排观赏，可以比较同一公司在不同时期制作的面容。
