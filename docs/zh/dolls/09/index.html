关于这件人偶

这是一件身穿藏青色外套、饰以金色编带、头戴三角帽、佩白色蕾丝领饰(jabot)的人偶，一身18世纪法国贵族少年的装扮。原作 Long Face Jumeau 最初就被设计成男孩女孩皆可装扮的中性面容，这件人偶便利用了这一特点，完成为男孩形象。

收藏记录中记载，这件人偶也以「Cody」的别名称呼。

背景故事

Long Face Jumeau 是巴黎人偶公司 Jumeau 于1879年推出的型号，据传是委托有「皇帝的雕塑家」之称的 Albert-Ernest Carrier-Belleuse(1824-1887)制作的。有说法称其以亨利四世幼年时的肖像为原型，它被誉为第一件由知名雕塑家制作原型的人偶。因其略带忧郁的神情，也被称为「Bebe Triste」，法语意为「忧伤的宝贝」。

其特征是耳朵单独塑形后，在烧制前贴在头部上；头部仅刻有尺寸编号，身体上则盖有蓝色印章。1880年代生产的原作极为珍稀，因此它成为如今瓷人偶制作者复刻最多的古董模具之一。
