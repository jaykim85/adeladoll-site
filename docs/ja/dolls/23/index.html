この人形について

プラチナブロンドの長い巻き毛に白いレースのブラウスとサテンのコルセット、チュールのスカートを着た人形「エルイーズ(Elouise)」です。リン・ハリソン(Lynn Harrison)の作品で、原型とモールドはイギリスの作家バニー・モリスとポール・ジャクソンが作りました。

このモールドは限定版で、商業用には制作されませんでした。販売用モールドがなく、作家が行ったセミナーに参加した人だけが作ることができた、それだけに珍しい人形です。

背景のはなし

バニー・モリスとポール・ジャクソンは共同で人形の原型を造形する作家チームで、Seeley'sを通じて18インチの全身ポーセリンの子ども人形「Angel」、胸像「Claire」、30インチのティーンシリーズ「Daisy Garland」、妖精シリーズなどを発表しました。バニー・モリスは手足を差し替えられる5インチのミニ人形「Popit」の「Dollies Galore」コレクションでも知られています。

セミナー専用モールドはポーセリンドールの世界の独特な伝統です。作家が自分の原型を一般販売せず、自ら教えるセミナーでのみ使うよう制限すると、参加者は作家の彩色法と衣装制作の方法をそのまま学びながら、限られた数の人形を完成させることになります。そうした人形には作家の手のぬくもりとともにセミナーの記録が込められています。
