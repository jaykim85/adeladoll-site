この人形について

ひだを寄せた白いレースのボンネットと淡いピンクのドレスを身につけ、茶色の髪に濃い色の目を持つ人形「エイプリル・ザ・フラート(April the Flirt)」です。シャーリー・ロイド(Shirley Lloyd)がケマー&ラインハルトのアンティーク人形をSeeley'sのモールドで復元した作品で、頭の後ろに「SEL」のイニシャルが刻まれています。

「フラート(Flirt)」という名前は、オリジナルの左右に動く「フラーティアイ」に由来します。この復元品の目が実際に動くかどうかは確認中で、動かない場合でもオリジナルの雰囲気を生かして横向きに入れてあります。ジョイス・マーチ(Joyce Murch)のセミナーで作られました。

シャーリー・ロイドはカナダのポーセリンドール作家リン・ハリソン(Lynn Harrison)の母で、100歳まで人形とともに過ごし、数年前の12月に世を去りました。このコレクションには彼女の作品が複数あります(21、22、24、25、26、32番)。

背景のはなし

フラーティアイは、寝かせると閉じるスリープアイに加えて、頭を傾けると瞳が左右に動いて流し目のような表情を作る仕掛けです。ケマー&ラインハルトは1916年頃の117N「マイン・ノイアー・リープリング」をはじめ複数のモデルにこうした目を用い、1910-20年代のドイツ人形で大きな人気を集めました。この人形のオリジナルは117Nとは別のモデルで、モールド番号は確認中です。

復元人形における作家のイニシャルは、署名であると同時に誠実さの証です。制作者は焼成前のグリーンウェアの状態で頭の後ろにイニシャルと年を刻みます。アンティーク人形にはこうした個人の署名がないため、この印だけで復元品であることが見分けられます。
