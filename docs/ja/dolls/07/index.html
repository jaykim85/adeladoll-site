この人形について

金髪の巻き毛に水色のチュールのドレスを着た人形です。白いレースで仕上げた袖と前身頃、刺繍の飾りが丁寧で、青い目とほんのり赤い頬が子どもらしい印象を与えます。

ドイツのアルマン・マルセイユ(Armand Marseille)のモールド390で作られたアンティークのオリジナルで、1905-1920年頃に制作されました。390はアルマン・マルセイユが最も多く作ったモールドで、ソケットヘッドを関節式コンポジションボディに載せた典型的な「ドリーフェイス」の少女人形です。

背景のはなし

モールド390は1900年頃から1930年代まで数十年にわたって大量生産され、今日最もよく出会うドイツのアンティーク人形となりました。首の後ろには「Armand Marseille / Germany / 390 / A (サイズ) M」形式のマークがあり、ガラスのスリープアイ、歯の見える開いた口、モヘアのウィッグが基本仕様です。同社の370がショルダーヘッドとして革のボディに使われたのに対し、390はソケットヘッドとしてコンポジションボディにはめ込んで使われました。

アルマン・マルセイユは1856年にロシアのサンクトペテルブルクで生まれ、1860年代にドイツへ移住し、1885年にテューリンゲンのケッペルスドルフの磁器工場を買い取って人形のヘッドを作り始めました。全盛期には1日約1,000個のヘッドを生産する世界最大級のメーカーで、1919年にエルンスト・ホイバッハと合併した後、1932年に分離してまもなく生産を終えました。このコレクションの2番(モールド1894)と並べて見ると、同じ会社が作った異なる時期の顔を比べることができます。
