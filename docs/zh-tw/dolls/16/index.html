Emily Jumeau (伊麗莎白時代服飾)

法國古董復刻 (Antique Reproduction)

關於這件人偶

這是一款紅髮人偶，身著16世紀英國伊麗莎白一世時代風格的禮服。粉色緞面長裙前方襯以織錦前片，垂掛珍珠鏈與飾物，頭上戴著當時流行的兜帽式頭飾。

頭部復刻自法國朱莫人偶，由Anna Miller使用Virginia LaVorgna的模具製作。服裝與Bob Severns共同完成。

背景故事

Virginia LaVorgna是活躍於美國得克薩斯州錫達希爾(Cedar Hill)的人偶製作者兼企業家，推出了廣受歡迎的瓷器顏料系列與古董人偶復刻模具。她與模具製作者Stan Shelsky合作，並以六位孫女的名字為模具命名而聞名。隨附的照片彩繪指南為初學者提供了極大幫助，該產品線於2024年1月被The Bell Collection收購。

Bob Severns是D.A.G Millie獎得主，教授法國時裝人偶與時代服飾已超過30年。在他的研習班上，學員不僅學習頭部製作，還會一同學習像這樣考證並再現特定時代服飾的過程。
