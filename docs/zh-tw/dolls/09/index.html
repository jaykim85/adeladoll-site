Long Face Jumeau (Cody)

關於這件人偶

這是一件身穿藏青色外套、飾以金色編帶、頭戴三角帽、佩白色蕾絲領飾(jabot)的人偶，一身18世紀法國貴族少年的裝扮。原作 Long Face Jumeau 最初就被設計成男孩女孩皆可裝扮的中性面容，這件人偶便利用了這一特點，完成為男孩形象。

這件人偶由 Barb Hurst 以 Seeley's 模具製作。別名「Cody」來自 Seeley's 的 Long Face Jumeau 模具名稱「Triste or Cody Jumeau」。Hurst 是活躍於加拿大安大略的瓷人偶藝術家(1942-2019)，8號的 Bru Jne 貝貝據傳也出自她之手。

背景故事

Long Face Jumeau 是巴黎人偶公司 Jumeau 於1879年推出的型號，據傳是委託有「皇帝的雕塑家」之稱的 Albert-Ernest Carrier-Belleuse(1824-1887)製作的。有說法稱其以亨利四世幼年時的肖像為原型，它被譽為第一件由知名雕塑家製作原型的人偶。因其略帶憂鬱的神情，也被稱為「Bebe Triste」，法語意為「憂傷的寶貝」。

其特徵是耳朵單獨塑形後，在燒製前貼在頭部上；頭部僅刻有尺寸編號，身體上則蓋有藍色印章。1880年代生產的原作極為珍稀，因此它成為如今瓷人偶製作者復刻最多的古董模具之一。
