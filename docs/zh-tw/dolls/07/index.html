關於這件人偶

這是一件金色捲髮、身穿淡藍色網紗長裙的人偶。以白色蕾絲收邊的袖口和前襟以及刺繡裝飾都十分用心，藍色眼睛和紅潤的臉頰透出孩童般的神態。

這是用德國 Armand Marseille 的模具390製作的古董原作，製作於約1905-1920年。390是 Armand Marseille 產量最多的模具，是將插接式頭部安裝在關節式複合材料身體上的典型「娃娃臉」少女人偶。

背景故事

模具390從1900年左右到1930年代，幾十年間大量生產，成為如今最常見的德國古董人偶。頸後有「Armand Marseille / Germany / 390 / A (尺寸) M」格式的標記，玻璃睡眠眼、露齒的張開嘴和馬海毛假髮是基本配置。與同公司的370作為肩式頭部用於小羊皮身體不同，390是插接式頭部，嵌入複合材料身體使用。

Armand Marseille 於1856年出生於俄國聖彼得堡，1860年代移居德國，1885年收購圖林根克佩爾斯多夫的瓷器工廠，開始製作人偶頭部。全盛期工廠每天生產約1,000個頭部，是世界最大規模的製造商之一；1919年與 Ernst Heubach 合併，1932年分離後不久便停止了生產。將這件作品與本系列的2號(模具1894)並排觀賞，可以比較同一公司在不同時期製作的面容。
