關於這件人偶

這是人偶「埃洛伊絲(Elouise)」，一頭鉑金色長卷發，身穿白色蕾絲襯衫、緞面束身衣與薄紗裙。作品出自Lynn Harrison之手，原型與模具由英國藝術家Bunny Morris與Paul Jackson製作。

這款模具為限量版，從未進行商業化生產。由於沒有出售的模具，只有參加過藝術家親自主持的研習班的人才能製作，因此這件人偶更加難得一見。

背景故事

Bunny Morris與Paul Jackson是共同雕塑人偶原型的藝術家組合，透過Seeley's釋出了18英寸全瓷兒童人偶「Angel」、半身像「Claire」、30英寸少女系列「Daisy Garland」以及精靈系列等。Bunny Morris還以可插拔更換四肢的5英寸迷你人偶「Popit」的「Dollies Galore」系列而聞名。

研習班專用模具是瓷人偶世界獨特的傳統。藝術家不公開出售自己的原型，而將其限定於親自授課的研習班中使用，參加者便能原原本本地學到藝術家的彩繪方法與服裝製作方式，同時完成數量有限的人偶。這樣的人偶既凝聚著藝術家的手藝，也承載著研習班的記錄。
